URA4 LOSS FREQUENCY CALCULATOR

Calculate ura4 loss frequency from paired YES and YES + 5-FOA colony counts, normalized to plating survival. Each independently plated culture is entered as one paired observation. The calculator also summarizes optional eviction/conversion characterization and allows user-defined statistical comparisons between strains.

CALCULATION LOGIC

The ura4 loss frequency is calculated by correcting the number of colonies growing on YES + 5-FOA for the survival/plating efficiency measured on YES plates.

1. Survival: YES colonies / 100

2. Survival-corrected 5-FOA colonies: 5-FOA colonies / survival

3. Ura4 loss frequency: survival-corrected 5-FOA colonies / 100,000 × 100

Lea–Coulson method of the median: estimates the number of mutation events per culture from the median number of resistant colonies across independent cultures. The calculator then converts this to a mutation rate using the final population size and, when the cultures have sufficiently similar sampling fractions and population sizes, a partial-plating correction. This is a separate mutation-rate analysis; it is not the median ura4-loss frequency reported by Zaratiegui et al. (2011).

The Eviction / Conversion Characterization is calculated separately and describes the composition of the ura4-loss events; it does not affect the ura4 loss frequency or the statistical comparisons.

MUTATION-RATE ANALYSIS

Lea–Coulson method of the median

This is the standard, built-in mutation-rate estimate. It uses the distribution of 5-FOA-resistant colony counts across independent cultures. The classical Lea–Coulson median equation is not, by itself, a partial-plating correction. Because your assay plates only a fraction of each culture, this calculator will only convert the classical estimate into a mutation rate when essentially the complete culture is represented. For your usual partial-plating design, use the optional mlemur workflow or a validated partial-plating estimator; the calculator will not apply an unsupported correction.

Optional analysis: mlemur (maximum-likelihood method)

mlemur: mlemur (MLE MUtation Rate calculator) uses maximum-likelihood methods to estimate mutation rates from the distribution of mutant counts across independent cultures. Unlike the classical Lea–Coulson method of the median, it can model several features that may affect fluctuation assays, including partial plating, cell death, phenotypic lag, variation in final population size and mutations arising after the exponential-growth phase. The model must be selected to match the experiment; these options should not be enabled automatically without supporting experimental information.

For this assay, each of the 12 cultures is an independent lineage started from a separate colony, grown overnight, refreshed separately and then plated. The 5-FOA colony counts, viable-cell measurements and actual plated fractions are therefore needed for each culture. A single-cell population estimate or a simple correction of colony counts by the plated fraction is not a substitute for the partial-plating likelihood model.

Important: This browser calculator does not reproduce the mlemur likelihood engine. It prepares the per-culture data for analysis in the published mlemur software and lets you record the resulting mutation-rate estimates and confidence intervals here. This avoids presenting an unvalidated in-browser approximation as an mlemur result.
